# 🌲 모여라 대전의 숲 (LocalHub - 대전)

공공데이터 기반 대전 지역 정보 공유 커뮤니티 플랫폼

> SSAFY 16기 데이터 트랙 팀 프로젝트 | 개발기간 2026.07.14 ~ 2026.07.16 15:00

---

## 📌 프로젝트 소개

블로그, SNS, 지도 앱 등 여러 채널에 흩어져 있는 대전 지역 정보(맛집·숙소·문화시설 등)를
**구(區) 단위 지도**와 **익명 커뮤니티**, **AI 챗봇**으로 한곳에 모아 제공하는 서비스입니다.

- **선정 권역**: 대전_충청권 (대전광역시 데이터 중심 활용)
- **핵심 문제**: 대전 지역 정보가 여러 채널에 흩어져 있어, 구 단위로 확인 가능한 신뢰도 있는 정보와 실시간 소통 창구 부재
- **타깃 사용자**: 대전 거주 청년/1인가구, 대전 방문 관광객, 동네 단위 정보를 빠르게 확인하고 싶은 사용자
- **성공 지표**: 게시글 등록 건수, 지도 핀 클릭 수, 챗봇 질의 응답 성공률, 배포 URL 정상 접속, 필수 기능 완료율

## 🖼️ 서비스 흐름

랜딩 (닉네임 입력)
↓
글로벌 헤더 (어디서든 '🌳 대전의 숲' 홈 버튼으로 랜딩 이동 가능)
↓
대전 지도 (구 선택)
↓
선택한 구 화면
├─ 다중 선택식(Filter-In) 카테고리 핀 지도 (기본 핀 없음 → 원하는 카테고리 다중 토글 시 핀 등장)
│     └─ 핀 클릭 → 기본정보 팝업 + 썸네일
│     └─ 팝업 내 링크 → 카카오맵 상세페이지 이동
├─ 커뮤니티 게시판 (목록/상세/작성/수정/삭제)
└─ AI 챗봇 위젯 (장소 추천 · 축제 일정 · 맛집 위치 · 게시글 검색 Q&A)

## 🛠️ 기술 스택 및 구현 상세

| 구분 | 기술 | 선정 이유 및 구현 상세 |
|---|---|---|
| **Frontend** | Vue.js 3 (SPA) | 빠른 초기 렌더링, 컴포넌트 기반 구조화, Netlify 정적 배포와 높은 호환성 |
| **Backend** | FastAPI | 비동기(Async) 처리 기반으로 AI 챗봇 및 데이터 조회 병목 해결, Swagger 자동 문서화 |
| **Database** | SQLite + SQLAlchemy ORM | 가볍고 단순한 서버리스 아키텍처로 배포 복잡도 최소화 및 `.db` 파일 보존 용이 |
| **AI** | OpenAI API | 자연어 지역 정보 질의응답 및 사용자 친화적 Q&A 위젯 구현 (`POST /api/chat`) |
| **지도 API** | Kakao Maps API | **행정구역 경계선 시각화(GeoJSON)**, **Ray-Casting 알고리즘**을 활용해 선택된 구(區) 폴리곤 내부의 핀만 걸러서 보여주는 동적 필터링 구현 |
| **Frontend 배포** | Netlify | 저장소(GitLab/GitHub) 연동 지속적 통합 및 자동 배포 |
| **Backend 배포** | Render | 저장소 연동 자동 배포 및 환경 변수 안전 관리 |
| **개발 도구** | VS Code + GitHub Copilot | **의뢰사 지정 환경 준수 (이외 AI 코딩 툴 사용 금지)** |

## 💡 핵심 구현 성과

1. **사용자 친화적 다중 필터링 (Filter-In Toggle):**
   * 초기 화면 진입 시에는 마커가 노출되지 않으며, 사용자가 상단 카테고리 칩(관광지, 음식점 등)을 클릭하면 실시간으로 해당 마커들만 활성화되어 누적되는 직관적인 필터 방식을 설계했습니다.
2. **자연스러운 네비게이션 및 UX 개선:**
   * 어떤 페이지에 있든 최상단의 **`🌳 대전의 숲` 글로벌 로고 버튼**을 통해 랜딩 페이지로 매끄럽게 되돌아올 수 있도록 설계했습니다.
   * 구 경계 폴리곤 마우스 오버 시 시각적 강조 효과(테두리/배경색 변화)를 주어 행정구역 선택의 직관성을 한층 더 높였습니다.
3. **AI 챗봇 공존성 극대화:**
   * 메인 랜딩 페이지를 제외한 모든 동적 콘텐츠 영역(`App.vue`)에서 대전 정보 검색 Q&A 비서인 `ChatWidget`이 충돌 없이 공존하도록 라우터 결합 흐름을 제어했습니다.

## 📊 데이터 출처

- **출처**: 한국관광공사 TourAPI 4.0 (`region: 대전_충청권`)
- **형식**: 의뢰사 사전 가공 제공 JSON (직접 공공 API 호출 불필요)
- **카테고리**: 관광지 · 문화시설 · 축제공연행사 · 여행코스 · 레포츠 · 숙박 · 쇼핑 · 음식점
- **비고**: 대전 외 충남·충북 데이터가 혼재되어 있어 `addr1` 필드 기준 대전광역시 항목만 필터링하여 사용. 라이선스(`cpyrhtDivCd`) 유형이 카테고리별로 상이하여 사전 확인 후 활용.

## ✅ 기능 범위 (MoSCoW)

### Must have (필수)
- 닉네임 기반 익명 커뮤니티 (로그인/계정 시스템 없음)
- 게시판 CRUD (제목/내용/수정용 비밀번호, 평문 비교 — 교육 목적 의도된 설계)
- 대전 지도 + 구 선택 + 카테고리별 색상 핀 (누적 필터 토글 구현)
- 챗봇 Q&A (장소 추천 · 축제 일정 · 맛집 위치 · 게시글 검색)
- FastAPI + SQLite 백엔드, Vue3 SPA 프론트
- Netlify / Render 배포, `.env` 기반 민감정보 관리

### Should / Could have (선택)
- 핀 클릭 시 상세정보 팝업 + 카카오맵 딥링크 (구현 완료)
- 글로벌 네비게이션 헤더 홈 버튼 (구현 완료)
- 게시판 조회수 / 검색 기능
- 소셜 공유(카카오 링크 복사)
- 실시간 채팅 (WebSocket) — 스트레치 목표
- 챗봇 채팅 요약 — 스트레치 목표

### Won't have (이번 범위 제외)
- 아이디/비밀번호 로그인 계정 시스템
- 다국어 지원, 날씨 연동, 경로 안내, 데이터 시각화 대시보드, 축제 캘린더
