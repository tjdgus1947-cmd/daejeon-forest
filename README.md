# 🌲 모여라 대전의 숲 (LocalHub - 대전)

공공데이터 기반 대전 지역 정보 공유 커뮤니티 플랫폼

> SSAFY 16기 데이터 트랙 팀 프로젝트 | 개발기간 2026.07.14 ~ 2026.07.16 15:00

---

## 📌 프로젝트 소개

블로그, SNS, 지도 앱 등 여러 채널에 흩어져 있는 대전 지역 정보(맛집·숙소·문화시설 등)를
**구(區) 단위 지도**와 **익명 커뮤니티**, **AI 챗봇**으로 한곳에 모아 제공하는 서비스입니다.

- **선정 권역**: 대전_충청권 (대전광역시 데이터 중심 활용)
- **핵심 문제**: 대전 지역 정보가 여러 채널에 흩어져 있어, 구 단위로 확인 가능한 신뢰도 있는 정보와 실시간 소통 창구 부재
- **타깃 사용자**: 대전 거주 청년/1인가구, 대전 방문 관광객, 동네 단위 정보를 빠르게 확인하고 싶은 사용자
- **성공 지표**: 게시글 등록 건수, 지도 핀 클릭 수, 챗봇 질의 응답 성공률, 배포 URL 정상 접속, 필수 기능 완료율

---

## 🖼️ 서비스 흐름

```
랜딩 (닉네임 입력)
   ↓
대전 지도 (구 선택)
   ↓
선택한 구 화면
 ├─ 카테고리별 색상 핀 지도 (식당/숙소/문화시설 등)
 │    └─ 핀 클릭 → 기본정보 + 썸네일
 │    └─ 재클릭 → 카카오맵 상세페이지 이동
 ├─ 커뮤니티 게시판 (목록/상세/작성/수정/삭제)
 └─ 챗봇 위젯 (장소 추천 · 축제 일정 · 맛집 위치 · 게시글 검색 Q&A)
```

## 🛠️ 기술 스택

| 구분 | 기술 | 선정 이유 |
|---|---|---|
| Frontend | Vue.js 3 (SPA) | 빠른 초기 렌더링, 낮은 학습곡선, Netlify 정적 배포와 궁합 |
| Backend | FastAPI | 비동기 처리로 챗봇(OpenAI 호출) 중에도 다른 요청 병목 없음, Swagger 자동 문서화 |
| Database | SQLite + SQLAlchemy ORM | 별도 DB 서버 불필요 → 배포 복잡도 최소화, `.db` 파일 단위 제출 가능 |
| AI | OpenAI API | 자연어 지역 정보 질의응답 (`POST /api/chat`) |
| 지도 | Kakao Maps / Leaflet.js | 카테고리별 색상 핀 시각화 |
| Frontend 배포 | Netlify | Repo 연동 자동 배포 |
| Backend 배포 | Render | Repo 연동 자동 배포 |
| 개발 도구 | VS Code + GitHub Copilot | **의뢰사 지정 환경, 이외 AI 코딩 도구(Claude Code, Codex, Cursor 등) 사용 금지** |

## 📊 데이터 출처

- **출처**: 한국관광공사 TourAPI 4.0 (`region: 대전_충청권`)
- **형식**: 의뢰사 사전 가공 제공 JSON (직접 공공 API 호출 불필요)
- **카테고리**: 관광지 · 문화시설 · 축제공연행사 · 여행코스 · 레포츠 · 숙박 · 쇼핑 · 음식점
- **비고**: 대전 외 충남·충북 데이터가 혼재되어 있어 `addr1` 필드 기준 대전광역시 항목만 필터링하여 사용. 라이선스(`cpyrhtDivCd`) 유형이 카테고리별로 상이하여 사전 확인 후 활용.

## ✅ 기능 범위 (MoSCoW)

### Must have (필수)
- 닉네임 기반 익명 커뮤니티 (로그인/계정 시스템 없음)
- 게시판 CRUD (제목/내용/수정용 비밀번호, 평문 비교 — 교육 목적 의도된 설계)
- 대전 지도 + 구 선택 + 카테고리별 색상 핀
- 챗봇 Q&A (장소 추천 · 축제 일정 · 맛집 위치 · 게시글 검색)
- FastAPI + SQLite 백엔드, Vue3 SPA 프론트
- Netlify / Render 배포, `.env` 기반 민감정보 관리

### Should / Could have (선택)
- 핀 클릭 시 상세정보 팝업 + 카카오맵 딥링크
- 게시판 조회수 / 검색 기능
- 소셜 공유(카카오 링크 복사)
- 실시간 채팅 (WebSocket) — 스트레치 목표
- 챗봇 채팅 요약 — 스트레치 목표

### Won't have (이번 범위 제외)
- 아이디/비밀번호 로그인 계정 시스템
- 다국어 지원, 날씨 연동, 경로 안내, 데이터 시각화 대시보드, 축제 캘린더
